# 📊 Bluestock Mutual Fund Analytics

## 📌 Project Overview

This project is part of the **Bluestock Fintech Data Analytics Internship**.

The objective of this project is to analyze mutual fund datasets, perform data quality checks, validate AMFI codes, and fetch live NAV data using the MFAPI. The project will progressively cover data cleaning, exploratory data analysis, SQL analysis, dashboard development, and business insights.
